# 文言编程手册

本手册介绍当前编辑器内置 Wenyan 编译器支持的常见写法。文言程序由关键字、中文标点和变量名组成；每条语句通常以句号 `。` 结束。编辑器支持关键字补全和结构片段补全，未识别的词法片段会在源码中标记。

## 快速开始

### 编写、检查、运行

1. 在左侧选择示例，或新建脚本开始编写。
2. 在编辑区输入代码。关键字、数字、字符串和变量会以不同颜色显示；按 `Ctrl+Space` 可打开补全菜单。
3. 点击“编译”生成 JavaScript 与 Python 转译结果；点击“运行”执行 JavaScript 并查看输出。
4. 修改代码后，语法检查会稍作等待再更新错误标记。悬停标记可查看错误信息。

下面是最短的完整程序：

```wenyan
吾有一言。曰「「你好，文言。」」。書之。
```

其中，`吾有一言` 声明字符串，`曰` 提供字符串内容，`書之` 输出表达式。程序不需要额外的入口函数。

## 基本语句与命名

### 一条语句的基本组成

常见语句由关键字、值和句号组成。句号用于结束一条语句；逗号、顿号等中文标点在复杂表达式中也可能出现。

```wenyan
吾有一數。曰三。名之曰「甲」。
夫「甲」。書之。
```

第一行依次完成“声明一个数字、设置初值、给它命名”。第二行用 `夫` 取出表达式，再用 `書之` 输出。

### 声明与命名

- `吾有` 表示声明一个局部值；其后写数量和类型，例如 `吾有一數`、`吾有一言`、`吾有一列`。
- `曰` 后提供初值。数值可直接写在 `曰` 后，字符串使用双层引号。
- `名之曰「名称」` 将结果保存为可复用的名字。变量名必须放在单层引号 `「...」` 中。
- 在后续表达式中，使用 `「名称」` 引用变量；不要把变量名写成字符串形式 `「「名称」」`。

```wenyan
吾有一數。曰三。名之曰「甲」。
吾有一數。曰五。名之曰「乙」。
加「甲」以「乙」。名之曰「和」。
夫「和」。書之。
```

中间结果建议立即命名。这样表达式较短，编译或运行出错时也更容易定位问题。

## 数据类型与字面值

### 常见类型

| 类型关键字 | 用途 | 示例 |
| --- | --- | --- |
| `數` | 数字和算术结果 | `吾有一數。曰三。名之曰「數值」。` |
| `言` | 文本 | `吾有一言。曰「「天地玄黃」」。名之曰「詞」。` |
| `列` | 有顺序的集合 | `吾有一列。名之曰「史」。` |
| `術` | 可调用的程序块 | 用 `吾有一術` 定义，见“术：定义与调用” |
| `爻` | 布尔值 | 关键字 `陽` 表示真，`陰` 表示假 |

`元` 表示不限定具体类型的值。初学时优先选用用途明确的 `數`、`言` 和 `列`。

### 数字与布尔值

整数可以使用汉字数字或阿拉伯数字。常见布尔字面值为 `陽` 和 `陰`。

```wenyan
吾有一數。曰十二。名之曰「漢字數」。
吾有一數。曰十。名之曰「另一數」。
吾有一爻。曰陽。名之曰「已完成」。
```

### 字符串与变量名

字符串使用双层引号，例如 `「「天地玄黃」」`；变量名和术名使用单层引号，例如 `「甲」`、`「求和」`。

```wenyan
吾有一言。曰「「這是一段文字。」」。名之曰「提示」。
夫「提示」。書之。
```

把字符串的双层引号误写成单层引号，是常见的语法错误。需要输出变量时，也不要额外添加一层字符串引号。

## 运算与比较

### 算术运算

算术关键字后先写左侧值，再用 `以` 引入右侧值。用 `名之曰` 保存计算结果。

| 运算 | 写法 | 说明 |
| --- | --- | --- |
| 加法 | `加「甲」以「乙」。` | 甲加乙 |
| 减法 | `減「甲」以「乙」。` | 甲减乙 |
| 乘法 | `乘「甲」以「乙」。` | 甲乘乙 |
| 除法 | `除「甲」以「乙」。` | 甲除以乙 |

```wenyan
吾有一數。曰十。名之曰「甲」。
吾有一數。曰四。名之曰「乙」。
減「甲」以「乙」。名之曰「差」。
夫「差」。書之。
```

### 比较

比较表达式通常放在 `若` 和 `者` 之间：

| 比较 | 关键字 | 示例 |
| --- | --- | --- |
| 等于 | `等於` | `若「甲」等於「乙」者。` |
| 不等于 | `不等於` | `若「甲」不等於零者。` |
| 大于 | `大於` | `若「甲」大於「乙」者。` |
| 小于 | `小於` | `若「甲」小於「乙」者。` |
| 不大于 | `不大於` | `若「甲」不大於「乙」者。` |
| 不小于 | `不小於` | `若「甲」不小於「乙」者。` |

当前运行时也提供 `中有陽乎`、`中無陰乎` 等逻辑关键字。为了让条件更容易读懂，建议先使用简单比较和嵌套条件。

## 条件判断

`若` 开始条件分支，条件后接 `者`。条件成立时执行其后的语句；用 `乃止也` 结束该分支。

```wenyan
吾有一數。曰三。名之曰「分數」。
為是一遍。
  若「分數」大於零者。
    吾有一言。曰「「分數為正。」」。書之。
    乃止也。
云云。
```

`若非` 可以开始否则分支；`或若` 可以添加另一个条件。下面用一次循环包住分支，让 `乃止也` 有明确的循环出口；实际编写时可将它放进需要提前退出的循环流程中。

```wenyan
為是一遍。
  若「分數」大於零者。
    吾有一言。曰「「正數」」。書之。
  若非。
    吾有一言。曰「「非正數」」。書之。
    乃止也。
云云。
```

复杂条件可以使用嵌套的 `若`。例如同时检查两个条件时，先判断第一个，再在其内部判断第二个。这样比把多个条件挤在一行更容易排查。

## 循环控制

### 固定次数循环

`為是「次數」遍。` 按给定次数重复执行主体，`云云` 标记循环主体结束。

```wenyan
為是三遍。
  吾有一言。曰「「行。」」。書之。
云云。
```

也可以用已命名的数字作为次数：

```wenyan
吾有一數。曰三。名之曰「次數」。
為是「次數」遍。
  吾有一言。曰「「重複執行。」」。書之。
云云。
```

### 条件循环与退出

`恆為是。` 开始恒真循环，满足退出条件时使用 `乃止`。检查退出条件应放在循环主体内，避免循环无法终止。

```wenyan
恆為是。
  若「計數」大於二者。
    乃止。
  乃止也。
云云。
```

### 遍历列表

`凡「列表」中之「元素」` 逐项遍历列表，`云云` 结束循环。循环变量表示当前元素。

```wenyan
凡「史」中之「篇」。
  夫「篇」。書之。
云云。
```

## 术：定义与调用

### 定义术

术相当于可重复调用的函数。定义依次包含术名、参数、主体和结束标记：

1. `吾有一術。名之曰「術名」。` 声明并命名术。
2. `欲行是術。必先得二數。曰「甲」。曰「乙」。` 声明所需参数及其名字。
3. `乃行是術曰。` 开始主体。
4. `乃得「結果」。` 返回结果。
5. `是謂「術名」之術也。` 结束定义。

```wenyan
吾有一術。名之曰「求和」。欲行是術。必先得二數。曰「甲」。曰「乙」。
乃行是術曰。
  加「甲」以「乙」。名之曰「和」。
  乃得「和」。
是謂「求和」之術也。
```

### 调用术

用 `施` 调用术，并用 `於` 按顺序传入参数。需要保存返回值时，在参数后添加 `名之曰`。

```wenyan
施「求和」於三。於五。名之曰「結果」。
夫「結果」。書之。
```

参数的声明顺序必须与调用时的传入顺序一致。术内变量尽量使用有意义的名字；计算、输出和格式化可以拆成不同的术，以便独立检查。

## 列表与索引

### 创建和填充

`吾有一列` 声明列表；`充「列表」以...` 将元素加入列表，连续的 `以` 可以提供多个元素。

```wenyan
吾有一列。名之曰「史」。
充「史」以「「春」」。以「「夏」」。以「「秋」」。以「「冬」」。
```

### 读取元素

`夫「列表」之一`、`夫「列表」之二` 分别读取第一项、第二项，索引从一开始计数。

```wenyan
夫「史」之一。名之曰「首項」。
夫「首項」。書之。
```

读取前应确保列表中存在对应项。空列表或超出范围的索引不应被当作有效值。

### 拼接列表

`銜` 可以将多个列表或值连接后命名为新的列表。

```wenyan
吾有一列。名之曰「前篇」。
充「前篇」以「「甲」」。
吾有一列。名之曰「後篇」。
充「後篇」以「「乙」」。
銜「前篇」以「後篇」。名之曰「全篇」。
```

## 编译与错误提示

编辑器会对关键字、字符串、变量和数字进行语法着色，并提供关键字和常用结构补全。按 `Ctrl+Space` 可以主动打开补全菜单。

输入后，编辑器会延迟执行词法检查。无法识别的语法会显示波浪线和提示；编译器捕获到的错误也会以标记方式反馈。点击“编译”可查看生成的 JavaScript 和 Python；点击“运行”会执行编译后的 JavaScript。

遇到错误时，可以按以下顺序检查：

1. 确认关键字拼写及繁简字形与运行时一致，例如 `術`、`數`、`減`。
2. 检查字符串是否使用双层引号 `「「...」」`，变量名是否使用单层引号 `「...」`。
3. 检查语句末尾的 `。`、条件分支的 `乃止也`、循环结束的 `云云` 是否完整。
4. 检查是否先声明变量或术，再引用它；检查 `施` 的参数个数与顺序。
5. 根据编辑器错误标记和运行输出定位出错语句，先编译最小片段，再逐步补回代码。

实时检查主要识别未能解析的语法片段；完整的语义和运行时错误仍需通过编译或运行发现。不同 Wenyan 实现对部分语法的支持可能不同，本编辑器以当前内置运行时的实际行为为准。

## 完整示例

以下程序定义一个求和术，调用后输出结果：

```wenyan
吾有一術。名之曰「求和」。欲行是術。必先得二數。曰「甲」。曰「乙」。
乃行是術曰。
  加「甲」以「乙」。名之曰「和」。
  乃得「和」。
是謂「求和」之術也。

施「求和」於三。於五。名之曰「結果」。
吾有一言。曰「「三加五等於：」」。書之。
夫「結果」。書之。
```

建议先独立编译并运行这段程序，再逐步改动参数、变量名和运算符，观察编辑器的高亮、补全、错误提示及运行结果。
