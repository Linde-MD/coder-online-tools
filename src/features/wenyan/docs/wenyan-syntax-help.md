# 文言语法速查

本说明参考 Wenyan README 的语法表整理为项目内速查版，便于在编辑器中快速检索。

## 1. 基本结构

| 用途 | 语法示例 | 说明 |
| --- | --- | --- |
| 声明数字 | 吾有一數。曰三。名之曰「甲」。 | 变量命名后可复用 |
| 声明字符串 | 吾有一言。曰「「天地玄黃」」。名之曰「詞」。 | 文言字符串常用双层引号 |
| 声明列表 | 吾有一列。名之曰「史」。 | 列表可用充、銜等操作 |
| 输出 | 夫「甲」。書之。 | 输出变量或表达式 |

## 2. 常用运算

| 运算 | 语法示例 |
| --- | --- |
| 加法 | 加「甲」以「乙」。名之曰「和」。 |
| 减法 | 減「甲」以「乙」。名之曰「差」。 |
| 乘法 | 乘「甲」以「乙」。名之曰「積」。 |
| 除法 | 除「甲」以「乙」。名之曰「商」。 |

### 2.1 比较与逻辑

| 场景 | 语法示例 | 说明 |
| --- | --- | --- |
| 相等判断 | 若「甲」等於「乙」者。...乃止也。 | 相等时进入分支 |
| 大小比较 | 若「甲」大於「乙」者。...乃止也。 | 常用于区间判断 |
| 与（AND） | 若（甲條件）者。若（乙條件）者。...乃止也。 | 文言常用嵌套若实现“且” |
| 或（OR） | 若（甲條件）者。...乃止也。若（乙條件）者。...乃止也。 | 分支并列实现“或” |
| 非（NOT） | 若「甲」不等於零者。...乃止也。 | 通过否定比较表达“非” |

> 说明：不同版本实现对“与/或/非”关键字支持不完全一致，建议优先使用嵌套若与显式比较，兼容性最好。

## 3. 条件与循环

| 场景 | 语法示例 | 说明 |
| --- | --- | --- |
| 条件判断 | 若「甲」等於零者。...乃止也。 | 满足条件执行并结束当前块 |
| 恒循环 | 恆為是。...乃止也。 | 需在内部使用乃止也退出 |
| 遍历 | 凡「史」中之「步」...云云。 | 逐项迭代 |

## 4. 术（函数）

| 步骤 | 语法示例 |
| --- | --- |
| 定义术 | 吾有一術。名之曰「求和」。欲行是術。必先得二數。曰「甲」。曰「乙」。乃行是術曰。...是謂「求和」之術也。 |
| 返回结果 | 乃得「和」。 |
| 调用术 | 施「求和」於三。於五。名之曰「結果」。 |

### 4.1 术的详细建议

1. 参数顺序就是调用顺序，调用时按 `施「术名」於參一。於參二。` 对应传入。
2. 术内中间量尽量 `名之曰` 后再复用，避免长表达式难调试。
3. 建议每个术只负责一件事：计算、格式化、输出分开写。
4. 若术可能失败，先写输入检查分支，再写主体逻辑。

示例：带输入检查的术

```wenyan
吾有一術。名之曰「安全相除」。欲行是術。必先得二數。曰「甲」。曰「乙」。
乃行是術曰。
	若「乙」等於零者。
		吾有一言。曰「「除數不可為零」」。書之。
		乃得零。
	乃止也。
	除「甲」以「乙」。名之曰「商」。
	乃得「商」。
是謂「安全相除」之術也。
```

## 5. 对象与结构化数据（工程实用）

Wenyan 本身更偏过程式，常用“列 + 固定索引”模拟对象/记录结构。

| 目标 | 推荐写法 | 说明 |
| --- | --- | --- |
| 模拟对象 | 吾有一列。充以「鍵」。以「值」。 | 用固定位置表达字段 |
| 模拟对象数组 | 吾有一列。充以「記錄甲」。以「記錄乙」。 | 列表元素再放“记录列” |
| 读取字段 | 夫「記錄」之一 / 之二 | 约定 1=key, 2=value 或自定义 |

示例：用“记录列”模拟对象

```wenyan
吾有一列。名之曰「車況」。
充「車況」以「「speed」」。以八十。
夫「車況」之一。名之曰「鍵」。
夫「車況」之二。名之曰「值」。
夫「鍵」。書之。
夫「值」。書之。
```

## 7. 注释与可读性

不同运行时对注释支持存在差异，工程中建议采用“字符串注释行”或“独立说明输出”方式，避免编译器不兼容。

推荐方式：

```wenyan
吾有一言。曰「「註：以下計算扭矩目標」」。
```

如果你使用的运行时支持注释关键字，可继续使用对应注释语法；若编译报错，请退回上面的兼容写法。

## 8. 实用建议

1. 先写小段并频繁点击编译，快速定位语法错误。
2. 术的入参与变量名尽量语义化，便于回读。
3. 多层控制流优先拆术，避免单文件过长。
4. 古书渲染用于展示，不建议替代源码审查。

## 9. 最小示例

```wenyan
吾有一數。曰三。名之曰「甲」。
吾有一數。曰五。名之曰「乙」。
加「甲」以「乙」。名之曰「和」。
夫「和」。書之。
```
