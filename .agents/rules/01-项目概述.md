# 项目概述

## 项目定位

本项目是一个基于 Vue 3 + Vite 的前端工具集合，围绕 CAN/J1939、图表和文言脚本等功能按 feature 分层组织。

## 技术边界

- UI 基于 Vue 3 SFC 和组合式 API。
- 路由使用 Vue Router，前端开发与构建使用 Vite。
- 现有架构以 app / features / shared / styles / scripts / tests 为主。
- 样式以 Tailwind 为优先方案，Bootstrap 仅保留兼容用法。
- 代码以 JavaScript 为主，不默认引入 TypeScript 重构。

## 技术栈约束

- 新功能优先使用项目已有依赖与封装；满足需求时复用 D3、Monaco Editor、Marked 等现有库，避免重复引入用途相近的依赖。
- 新增依赖前先确认现有技术栈无法合理满足需求，并控制依赖数量。
- 测试沿用 Vitest 与现有测试组织方式。

## 约束

- 新实现必须优先贴合现有 feature 化架构。
- 不允许为了局部便利破坏现有分层。
