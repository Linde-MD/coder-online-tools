# 样式规范

## 基础原则

- 样式优先使用 Tailwind 原子类。
- 已有 Bootstrap 仅做兼容，禁止继续扩散新的 Bootstrap 依赖。
- 新样式必须符合 DESIGN.md 和当前页面风格。

## 颜色与主题

- 主题色、边框、背景等优先使用 CSS 变量或项目已有 token。
- 不要在组件里随意硬编码一套新的视觉体系。

## 视觉边界

- 选中态、错误态、悬停态必须区分明确，且不要依赖偶然的布局差异来表达状态。
