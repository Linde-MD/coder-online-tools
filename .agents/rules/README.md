# Rules 索引

## 使用方式

- 这是项目级规则库。
- 总入口是 [.github/copilot-instructions.md](../../.github/copilot-instructions.md)，它负责引用这里的拆分规则。
- 先判断当前任务属于哪类决策，再读取对应规则文件。
- Rules 只放「是什么 / 不能是什么」；多步骤流程、检查清单、示例和产出模板放 Skills。
