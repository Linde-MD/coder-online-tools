# 编码规范

## 基础原则

- 代码优先清晰、可读、可测试、可维护。
- 函数保持单一职责，输入输出明确。
- 优先纯函数、显式传参和组合式写法。

## 命名规范

- 变量、函数、文件名使用能表达业务含义的英文命名。
- 组件名使用 PascalCase，组合式函数使用 `use` 前缀。
- 事件处理优先使用 `onXxx` 或 `handleXxx`，命名要区分对外事件和内部处理。

## JavaScript 约束

- 不要为了图省事把多个职责塞进一个函数。
- 不要使用含义不清的临时缩写变量。
- 除非确有必要，不要引入多余抽象或过度模式化实现。
