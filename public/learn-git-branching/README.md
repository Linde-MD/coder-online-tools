# LearnGitBranching 静态构建

本目录包含 LearnGitBranching 的本地静态构建，供本项目的 Git 学习功能离线运行。

- 上游项目：https://github.com/pcottle/learnGitBranching
- 上游版本：0.8.0
- 固定提交：`30855ac924472ee622c8fec3a75a016efbc1c8e4`
- 许可证：MIT，详见同目录 `LICENSE.md`

上游构建中的 Google Analytics、随机产品推广、GitHub 角标及相关外链入口已从页面移除；外层页面也会拦截练习器中的外站链接。当前功能无需登录，练习进度保存在浏览器本地。

本学习器通过 iframe 嵌入。可点击欢迎对话框中的沙盒链接，或学习器右下角的沙盒按钮进入；进入沙盒后，可使用外层工具栏的“返回关卡”按钮退出。

不要删除 `LICENSE.md` 与本来源说明。升级该静态应用时，请重新检查并移除上游新增的分析、推广和外跳入口，同时保留 Git 学习核心功能与许可证信息。
